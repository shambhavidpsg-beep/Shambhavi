# 🌐 Web Development Projects

Welcome to my Web Development repository! 🚀

This repository is a collection of my hands-on web development projects created while exploring **HTML, CSS, UI design, interactive web experiences, and problem-solving through front-end development**.

Each project focuses on a different concept, from practical utilities to creative and themed website designs.

---

## ✨ Projects

### 🧮 Calculator
A simple and user-friendly calculator interface designed to perform basic arithmetic operations.

**Concepts explored:**
- HTML structure
- CSS styling
- User interface design
- Interactive elements

---

### 🍳 FindRecipe
A recipe-finding web project designed to make discovering food ideas simple and engaging.

**Concepts explored:**
- Web page structure
- UI/UX design
- Content organization
- Responsive layout concepts

---

### 🪄 Hogwarts Staircase Inspired Website
A Harry Potter-inspired creative website based on the magical moving staircase concept.

The staircase moves as the user scrolls, with different floors revealing different magical sections and content.

**Concepts explored:**
- Creative UI design
- Scroll-based interactions
- CSS animations
- Themed web design
- Storytelling through web interfaces

---

### 🏫 SHE CAN Foundation Website
A website concept created for **SHE CAN Foundation**, focusing on presenting an organization's purpose, initiatives, and impact through a clean web interface.

**Concepts explored:**
- Organizational website design
- Content presentation
- Layout and navigation
- User-friendly interface design
